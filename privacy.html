PRIVACY POLICY

개인정보처리방침

숏템루프는 계정 연결에 필요한 정보와 제작 과정에서 입력된 정보를 아래 목적과 범위에서 처리합니다.

1. 처리하는 정보와 목적

  • SNS 계정 연결: 사용자가 승인한 계정의 식별자, 표시 이름, 프로필 이미지 주소, 승인 범위, 연결·만료 시각, 접근 토큰과 갱신 토큰을 처리합니다. 연결 상태와 계정 정보를 표시하고 연결을 유지하는 데 사용합니다.
  • 영상 제작: 사용자가 입력하거나 선택한 상품 정보, 이미지·영상, 대본과 제작 설정을 영상 제작과 결과 확인에 사용합니다.
  • TikTok 초안 전송: 사용자가 전송을 요청하면 승인된 영상 파일을 TikTok으로 보내고, 작업 번호·영상 식별자·TikTok 전송 식별자·처리 상태와 시각을 로컬에 기록하여 중복 전송을 막고 결과를 확인합니다.
  • 접속 과정: 계정 연결 과정에서 인증 상태를 확인하기 위한 임시 쿠키를 사용할 수 있습니다.

2. TikTok Login Kit 및 영상 전송

TikTok 계정 연결 시 user.info.basic 권한으로 계정 식별자, 표시 이름과 프로필 이미지 주소를 요청합니다. 사용자가 초안 전송을 선택하면 별도로 video.upload 권한을 요청합니다. 승인받은 토큰은 서버에서 암호화해 저장합니다. 사용자가 전송 버튼을 누른 경우에만 영상 파일을 TikTok으로 보내며, 게시 자체는 사용자가 TikTok 앱에서 진행합니다.

3. 보관과 삭제

연결된 계정 정보는 연결을 유지하는 동안 보관합니다. 이용자가 계정 연결을 해제하면 서비스에 저장된 해당 연결 정보를 삭제하며, 가능한 경우 플랫폼에 토큰 철회를 요청합니다. TikTok 전송 기록은 중복 방지와 상태 확인을 위해 로컬에 보관하며, 삭제가 필요하면 아래 문의처로 요청할 수 있습니다. 제작 자료와 결과물의 보관은 이용 환경과 제작 설정에 따라 달라질 수 있습니다.

4. 외부 서비스와 정보 전달

SNS 계정 인증과 프로필 확인을 위해 이용자가 선택한 플랫폼의 API와 통신합니다. 영상 제작 기능을 사용하는 경우 해당 기능에 설정된 외부 AI·음성·미디어 제공자에게 입력 정보가 전달될 수 있습니다. 이 경우 각 서비스의 설정과 정책도 함께 적용됩니다.

5. 보호 조치

서비스는 SNS 접근 토큰을 암호화해 저장합니다. 계정 연결 과정에서 승인 상태를 확인하며, 연결 해제 기능을 제공합니다. 이용자는 계정 승인 화면에서 요청 권한을 확인할 수 있습니다.
