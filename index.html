WORKFLOW

숏템루프에서 하는 일

01

상품 정보 검토

상품 제목, 이미지, 설명과 확인된 정보를 살펴보고 영상에 사용할 상품을 선택합니다.

02

대본과 영상 제작

대본을 확인하고 음성, 자막, 음악과 영상 구성을 설정해 결과물을 제작합니다.

03

결과 확인

완성된 영상을 미리 보고 필요한 부분을 검토합니다. SNS 게시에는 별도 권한과 설정이 필요합니다.

ACCOUNT CONNECTION

SNS 계정 연결

지원하는 SNS 계정을 사용자가 직접 승인해 연결하고, 연결된 계정의 이름과 프로필을 확인할 수 있습니다. TikTok 연결에는 Login Kit의 기본 프로필 권한을 사용합니다.

계정 연결은 사용자의 승인으로 시작됩니다. 계정 연결 화면에서 연결을 해제할 수 있습니다. 현재 이 기능만으로 TikTok에 영상을 게시하지는 않습니다.
